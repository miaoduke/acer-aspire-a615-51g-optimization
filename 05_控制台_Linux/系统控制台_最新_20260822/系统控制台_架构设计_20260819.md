# 系统控制台 — 架构设计 v1

> 日期：2026-08-19
> 技术栈：Python 3 + GTK3（Cinnamon 原生主题、Cairo 渲染）
> 原则：占用小（40-80MB）、省电（自适应采样）、高效（直读 /proc/sysfs）、快速（启动 <0.3s）
> 依据：控制台软件_调研汇总_20260819.md（第六节资源占用专项）

## 一、总体结构

```
项目目录: 性能优化方案/系统控制台/
├── console.py       入口：GTK 应用、主窗口、导航、采样调度（GLib 定时器合并主循环）
├── collector.py     数据采集：/proc + /sysfs 直读（无子进程），RAPL/GPU 差分计算
├── controller.py    控制封装：sudo 调用已验证脚本（场景管理.sh / m3.sh / prime-select）
├── ui_dashboard.py  Dashboard 页：4 状态卡 + CPU 曲线(Cairo) + 详细数值表
├── ui_scenes.py     电源场景页：6 场景卡 + 当前状态 + M3 状态入口
├── ui_advanced.py   高级控制页：PL/Turbo/降压状态 + GPU 模式 + 服务状态
└── install.sh       安装脚本：sudoers 白名单 + RAPL 读权限服务 + 桌面入口
```

## 二、数据流

```
GLib.timeout_add(1s) ──> tick()
   │ 可见: 1s 间隔 / 最小化: 暂停 / 后台(窗口失焦): 5s
   ├─ collector.sample() → dict{温度,功耗,CPU每线程%,内存,电池,GPU,PL,Turbo,EPP,场景状态}
   │     ├─ /proc/stat 差分（CPU%）
   │     ├─ /sys/class/powercap/intel-rapl:0/energy_uj 差分（功耗W）
   │     ├─ /sys/class/thermal/thermal_zone0/temp（温度）
   │     ├─ /proc/meminfo（内存）
   │     ├─ /sys/class/power_supply/BAT1/*（电池）
   │     ├─ nvidia-smi 每 3s 一次（GPU，独显模式才调用）
   │     └─ 各 sysfs 状态读取
   ├─ ring buffer(120 点) → Cairo 折线图（仅重绘变化区域）
   └─ UI 更新：标签/进度条/曲线
```

**省电设计**：
- 采样定时器与 GTK 主循环合并（无额外线程、无额外唤醒）
- 前台 1s / 失焦 5s / 最小化停止 —— 后台功耗可忽略
- 控制操作全部按需执行，绝不轮询

## 三、控制后端（复用已验证资产）

| 操作 | 调用 | 说明 |
|---|---|---|
| 6 场景切换 | `sudo 场景管理.sh <scene>` | 内部全部逻辑已实测（PL/Turbo/EPP/C-state/WiFi/USB） |
| M3 模式 | `sudo m3.sh on/off` | 非交互管道下自动跳过 GPU 交互（EOF 读空） |
| GPU 切换 | `sudo prime-select intel|nvidia` | 切换后 UI 提示需重启生效 |
| 场景状态 | `场景管理.sh status` 输出解析 | |

**权限方案**（安装时一次性配置，之后无感）：
1. `/etc/sudoers.d/system-console`：严格白名单（仅 3 条路径，无通配符）
   - 场景管理.sh、m3.sh、/usr/bin/prime-select
2. systemd 服务 `console-rapl-perm.service`：开机 `chmod 444 intel-rapl*/energy_uj`
   （RAPL 普通用户可读，监控免 sudo）

## 四、UI 布局

```
┌──────────────────────────────────────────┐
│ HeaderBar: 系统控制台 | 状态徽标(AC/DC,场景) │
├──────────┬───────────────────────────────┤
│ 左侧导航  │  GtkStack 页面                │
│ ▸ 总览    │  Dashboard:                  │
│   场景    │   [温度][功耗][电池][AC/DC] 4卡 │
│   高级    │   CPU 曲线(Cairo)             │
│          │   明细表(频率/内存/GPU/PL…)    │
└──────────┴───────────────────────────────┘
```

- 总览页：4 状态卡（温度/整机功耗/电池%/供电）+ CPU 每线程曲线 + 明细
- 场景页：6 场景按钮卡（名称+说明+当前高亮）+ 当前参数快照 + M3 入口
- 高级页：PL1/PL2 显示、Turbo 开关、降压状态（只读）、GPU 模式按钮、5 服务+rasdaemon 状态、死机事件计数

## 五、v1 范围与后续

**v1（本次）**：总览 + 场景 + 高级 三页（★★★ 全部）
**v2 候选**：电池保养页、基准测试页（bench 一键+历史对比）、MCE 事件页、托盘常驻、历史持久化（CSV）

## 六、验收标准

- 启动 <0.5s，内存 <80MB，前台 CPU <0.5%，后台可忽略
- 6 场景切换成功且状态回显正确
- GPU 切换正确提示重启
- 最小化/失焦后采样自动降频或停止
