# 显示体验优化方案（屏幕专项调研）
**日期**: 2026-08-22
**面板档案**: BOE NV156FHM-N42 · 15.6" FHD (1920×1080, 141PPI) · 60Hz · IPS · 2016 W1 生产
**调光方式**: intel_backlight raw（Intel PCH PWM，频率由 VBT 固化，软件不可调）
**色域**: ~45% NTSC 低色域面板（colord 自动 ICC 已生成，非校色仪实测）

---

## 一、科学结论：本机显示功耗的完整图景

| 因素 | 影响功耗? | 说明 |
|------|----------|------|
| **背光亮度** | ✅ **唯一大头** | LCD 背光恒定发光。亮度 100%→30% 可省 3-5W（占离电总功耗 25-40%）|
| 画面内容（黑白/暗色） | ❌ 零影响 | 实测黑/白屏 ±0.04W 噪声级；液晶只滤光不发电 |
| 刷新率 60Hz | 固定 | EDID 锁死，无法降也无法升 |
| 分辨率/缩放 | 微小 | iGPU 负载相关，1080p 已是原生 |
| 夜间色温 | ❌ 不省电 | gamma 变换在 GPU，开销可忽略 |

**离电显示省电 = 只有一条路：背光亮度管理（已实现 AC/DC 联动）**

---

## 二、显示"体验"（非功耗）优化项盘点

### A. 立即可做（推荐）

#### A1. 夜间护眼色温 ⭐推荐
```
现状: night-light-enabled = false（色温预设 2700K 未启用）
建议: 启用 + 日落到日出自动（或 20:00-07:00 定时）
收益: 夜间观感舒适度显著提升；蓝光减少助眠
成本: 零（gamma LUT 变换）
操作: 系统设置 → 显示 → 夜光灯
```

#### A2. PWM 频闪认知与使用建议
```
事实: BOE N42 属低频 PWM 调光面板（VBT 固化约 200Hz~1kHz 区间，
      Linux 无法修改频率）
风险: 亮度越低 PWM 占空比越小 → 频闪越明显 → 部分人眼疲劳/头痛
建议: 
  - 避免长期在最低亮度段使用（≤10%）
  - 眼睛敏感者用中高亮度 + 环境光补光
  - 无法软件修复（换 DC 调光面板是唯一根治法）
```

#### A3. 离电动画减负（流畅感）⭐可选
```
现状: enable-animations = true（恒定）
建议: 离电时自动关动画 → 窗口/菜单响应更跟手（iGPU 减负）
实现: acdc-profile v10 加一行
      DC 时: gsettings set org.cinnamon.desktop.interface enable-animations false
      AC 时: 恢复 true
收益: 低端 iGPU 上动画掉帧消失，交互延迟降低
代价: 失去窗口动画美观（可接受度高）
```

### B. 视情况做

#### B1. 色彩校准
```
现状: colord 自动 ICC（EDID 理论值），45% NTSC 面板出厂偏差大
方案A: 无校色仪 → 用网上 N42 同款面板的社区 ICC（需找到可信源）
方案B: 校色仪（Spyder/X-Rite）实测生成——最准确但要硬件
评估: 若不做设计/修图，出厂色彩够日常用；优先级低
```

#### B2. 字体渲染微调
```
现状: fontconfig 默认（Noto Sans CJK SC），无用户级覆盖
可选: ~/.config/fontconfig/fonts.conf 设置 hinting=slight + rgba=rgb
收益: 文字边缘锐度小幅提升（主观）
```

### C. 不做（有依据）

| 项 | 原因 |
|----|------|
| 刷新率超频 (>60Hz) | eDP 面板锁死，强设黑屏风险；收益仅 60→65Hz |
| 黑白/暗色主题省电 | 实测零差异（LCD 背光恒定） |
| PSR/IPS 静态刷新 | Kaby Lake-R 死机 bug（fdo#112159） |
| CABC 内容自适应背光 | 本机面板/驱动不支持（debugfs 无接口） |
| PWM 频率调整 | VBT 固化，i915 无用户态接口 |
| HiDPI 缩放 | 141 PPI 标准密度无需缩放 |

## 三、实施方案（A1 + A3）

### A1 夜间色温（一条命令 + 定时）
```bash
gsettings set org.cinnamon.settings-daemon.plugins.color night-light-enabled true
# 自动模式（日落日出）或定时:
gsettings set org.cinnamon.settings-daemon.plugins.color night-light-schedule-automatic true
# 色温调节范围 1700K(暖)-4700K(微暖)，2700K 为默认舒适值
```

### A3 离电动画减负（acdc-profile v10）
```bash
# DC 场景追加:
gsettings set org.cinnamon.desktop.interface enable-animations false
# AC 场景追加:
gsettings set org.cinnamon.desktop.interface enable-animations true
# 注意: acdc-profile 以 root 运行，gsettings 需要用户会话环境——
# 实现方式改为: 场景脚本写标记文件，控制台 tick 监听执行 gsettings
```
