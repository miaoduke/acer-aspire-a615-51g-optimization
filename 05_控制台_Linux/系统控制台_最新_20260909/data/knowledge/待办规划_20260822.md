# 待办科学规划（2026-08-22 制定）

## 核心原则
1. **单变量原则**: C-state=4 验证期内不叠加新系统变量（否则闪烁消失/持续无法归因）
2. **观察期门槛**: 每个高风险变更需前一项稳定满观察窗才解锁下一项
3. **用户操作项与系统项并行**: 不占观察窗口的任务随时可做

---

## Phase 0 —— 稳定观察窗口（现在 → +48h）
**目标**: 验证 C-state=4 是否解决待机闪屏；确认重建栈整体稳定
| 监测点 | 方式 | 判定 |
|--------|------|------|
| 待机/无操作闪烁 | 用户体感 | 消失=C8 根因确认；复发→回滚 max_cstate=1 |
| undervolt -50mV | 控制台/undervolt -r | 保持 -49.8mV 无漂移 |
| 温度/功耗基线 | 科学分析页自动积累 | 建立新基线供后续对比 |
| 服务四件套 | kernel_guard check | 全 ✓ |

⚠ 本阶段禁止: 改 GRUB/undervolt 步进/任何 MSR 写入/服务变更
✓ 本阶段可做: 日常使用积累电池数据（自动）

## Phase 1 —— 低风险快速项（+48h，C-state=4 稳定后）

## Phase 2 —— undervolt 步进（+7 天，-50mV 连续稳定）
| 步骤 | 动作 | 观察窗 |
|------|------|--------|
| 1 | -50 → -60mV | ≥72h |
| 2 | 稳定则 -70mV | ≥72h |
| 3 | 上限 -80mV 封顶 | 死机史红线附近，不再深入 |
| 异常处理 | 任何冻结/死机 → 回退上一档并终止步进 | — |
