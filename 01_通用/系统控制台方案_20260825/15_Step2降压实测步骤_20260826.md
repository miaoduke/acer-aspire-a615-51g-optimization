# Step 2 实测步骤 — ThrottleStop 降压阶梯 (拍板后执行)
> 前置: 用户拍板"关闭内存完整性"的安全权衡 (唯一待决策项)
> 原则: 逐级实测, 读回验证, 不做压力测试 (日常负载代理), 任档不稳即回退
> 已知: 本机固件不锁 (Linux -100mV 稳定/-105 死机红线) · 微码 0xE0 (影响由首档读回直接检验) · HVCI=1 是闸门

---

## 准备 (10 分钟)
1. **重新下载 ThrottleStop 9.7** — 现有 zip 损坏 (8/11 下载不完整, 35KB/73KB 均无尾记录)
   → techpowerup.com/download/techpowerup-throttlestop/ 浏览器下载, 解压到 Win_20260825\ThrottleStop_20260811\TS9.7\
2. **关闭内存完整性**: 设置 → 隐私和安全 → Windows 安全中心 → 设备安全性 → 内核隔离 → 内存完整性 **关** → 重启
3. 重启后确认: `Get-CimInstance -Namespace root\Microsoft\Windows\DeviceGuard Win32_DeviceGuard` 的 VirtualizationBasedSecurityStatus 应变为 0 或 1 (非 Running)

## 阶梯实测 (每档 ~10 分钟)
| 档 | 操作 | 判据 (全过才进下一档) |
|---|---|---|
| **-10mV** | TS → FIVR → 勾 FIVR Control → CPU Core/Cache 偏移 -10.0mV → Apply → **立即读回** | FIVR 窗口读回 = -10.0mV (HWiNFO 交叉更佳) |
| -25mV | 同上改 -25.0 | 读回一致 + 日常办公 10 分钟无异常 |
| -50mV | 同上 -50.0 (Linux 侧验证过的安全档) | 同上 + 温度对比基线 (预期 -2~4°C) |
| -75mV | 同上 | 同上 |
| -100mV | 同上 (Linux 稳定上限) | 同上; **定格此档长期使用** |
| -105mV | ⛔ **禁止** (Linux 侧已知死机红线) | — |

### 读回不一致 = 微码 0xE0 拒绝偏压
→ 记录现象, 二选一: ①终止本线 (恢复内存完整性) ②BIOS 关 VT 再试 (代价: Hyper-V/WSL2 全废, **默认不建议**)

### 日常负载验证法 (替代压力测试, 铁律)
- 每档: 正常办公/浏览 10 分钟 → 控制台曲线看 CPU 温度/频率 vs 档位前
- 判据: 无死机/无应用崩溃/温度下降即视为稳定
- TS Bench (TS 自带, 轻量) 可选做 1 分钟快速验证, **不用 OCCT/Cinebench 长跑**

## PL1/PL2 (可选, 降压通过后)
TS → TPL → Long Power Max (PL1) / Short Power Max (PL2) → 目标值建议 25W/25W (对齐 Linux 定稿) → 读回验证

## 回滚 (任一步骤不满意)
1. TS FIVR → Disable/Turn Off → 恢复默认电压
2. 内存完整性 **开** → 重启 (HVCI 防护恢复, 降压随之失效——本质权衡)
3. 全部记录写入 09A

## 长期使用形态
- TS 开机自启 (TS 内设置) + 最小化; 控制台负责监控+EPP+场景, TS 只管电压/PL
- Defender 若标记 TS 的 WinRing0 → 加排除项或终止 (不对抗杀软)
