## 一、开发环境实测结论（决定选型）

| 探测项 | 结果 |
|---|---|
| Python | ❌ 未安装（仅 Store 占位符） |
| csc.exe (.NET Framework 4.8 编译器) | ✅ `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe` 存在 |
| .NET Framework 运行时 | ✅ 4.8.09221（Release 533509） |
| winget | ✅ 可用（备选安装路径） |

### 选型决策：C# + WinForms + 系统自带 csc 编译
| 对比项 | C#/WinForms(csc) | Python+tkinter | PowerShell+WPF |
|---|---|---|---|
| 安装依赖 | **零**（系统自带编译器+运行时） | 需装 Python+pip 包 | 零 |
| 启动速度 | <0.5s | ~1s | 1–2s |
| 内存预估 | 25–45MB | 30–50MB | 60–120MB |
| 单文件分发 | ✅ 一个 exe | 需解释器 | 需 ps1 |
| 与 Linux 版理念契合（占用小/省电/快） | ★★★ | ★★ | ★ |

延续 Linux 控制台四原则：**占用小、省电（自适应采样）、高效（直读 API）、快速启动**。

## 二、数据源可行性实测（本机逐项验证）

| 数据 | API | 实测结果 |
|---|---|---|
| CPU 总量+每核 % | PerformanceCounter `Processor\% Processor Time`（实例 0–7/_Total） | ✅ |
| 内存 | GlobalMemoryStatusEx P/Invoke | ✅（标准 API） |
| GPU 3D 利用率 | `GPU Engine(*engtype_3D)\Utilization Percentage` | ✅ 实测 10.2% |
| GPU 显存 | `GPU Adapter Memory\Dedicated Usage` | ⚠ 类别存在但读数 0（iGPU 动态分配特性），显示并标注 |
| 磁盘 IO/繁忙 | `PhysicalDisk(_Total)` | ✅ |
| 网络 per-NIC | `Network Interface(*)\Bytes *`（Realtek GbE + QCA9377 WiFi） | ✅ |
| 电池 | `SystemInformation.PowerStatus` | ✅ 91% / Online |
| **ACPI 温度区** | WMI root/WMI `MSAcpi_ThermalZoneTemperature` | ⚠ **普通权限拒绝访问** → 需管理员；提供"以管理员重启"入口，不可用时明示 |
| 电源计划 | `powercfg /list` | ✅ 平衡/静音/**高性能(当前)**/省电 四方案——天然对标 Linux 六场景概念 |
| 计划切换 | `powercfg /setactive` | 运行时检测权限，失败则提示提权路径 |
| 进程 CPU%/内存 | `Process.TotalProcessorTime` 差分 / WorkingSet64 | ✅（标准 API） |
| 开机时长 | GetTickCount64 P/Invoke | ✅ |

## 三、v1 功能范围（对标 Linux 控制台页面结构）

```
系统控制台.exe（单文件，托盘常驻）
├── 总览页   状态卡(CPU/RAM/GPU/电池) + CPU历史曲线(自绘) + 每核柱条
│            + 内存条 + 磁盘占用/IO + 网卡速率 + 温度行(ACPI,需管理员) + 开机时长
├── 电源页   电池卡(%、充放状态、剩余时间) + 电源计划列表[切换]
│            + 生成电池报告(powercfg /batteryreport) + 提权提示
├── 进程页   ListView(名称/PID/CPU%/内存) 点列排序 + 结束任务(确认框)
└── 系统页   OS/CPU/主板/BIOS/.NET/分辨率信息 + 以管理员重启
             + 快捷入口(任务管理器/事件查看器/设备管理器)
托盘        图标 tooltip: CPU/RAM/电池实时摘要；双击唤出；右键菜单
省电设计    前台 1s 采样 / 最小化或失焦 5s / 托盘仅 tooltip 更新（对齐 Linux 版自适应采样）
```

## 五、已知限制与后续路线

| 限制 | 说明 | 后续 |
|---|---|---|
| CPU 核心温度不可读（普通权限） | Windows 无内核驱动不下发 coretemp；ACPI 温区也需管理员 | v2 可选集成 LibreHardwareMonitorLib（MIT）获取核心温度/风扇/电压 |
| GPU 显存读数 0 | iGPU 显存动态分配，计数器不反映 | 标注显示；独显模式下 nvidia-smi 路径可加 |
| 电源计划切换可能需管理员 | 视系统策略 | 运行时检测 + 一键提权重启 |
| 无开机自启/无通知中心告警 | v1 范围外 | v2：HKCU Run 注册开关 + 温度/电量 toast |
