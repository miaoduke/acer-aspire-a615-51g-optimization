## 二、逐项目穷尽 — 可借鉴清单

### G-Helper (14.9k★, Asus)
| 功能 | 机制 | 对本机适用性 |
|---|---|---|
| **GPU 四模式: Eco/Standard/Ultimate/Optimized** | Asus 驱动接口断开 dGPU 供电 (Eco) / Optimized=电池自动 Eco | 💡**思路可移植**: Optimus 断 dGPU 是真续航大招 (见 LLT 条目) |
| 性能模式=BIOS 烘焙 (含功耗墙+风扇曲线) | Asus System Control Interface 驱动 | ❌ 本机固件无烘焙模式 (仅 EC 三档, 已实现) |
| 刷新率自动切换 (电池 60Hz/插电最大) | Display API | 💡 可做: 零成本省电 (本机 60Hz 屏则无意义 — **待确认屏幕刷新率**) |
| 电池充电限制 | Asus WMI | ❌ 本机固件无接口 (已判) |
| Metrics Overlay (FPS/温度 OSD) | 自研注入 | ⛔ 我们拒绝注入类 |
| NV GPU 超频/降压 | NvAPIWrapper | ⚠️ MX150 功耗表损坏 (5001W), 功耗墙不可调; 核心偏移理论可行但脆弱 (11_文档已判) |
| AMD 降压 (Ryzen SMU/PawnIO) | PawnIO | ❌ Intel 8250U 不适用 |
| BIOS/驱动更新检查 | 官网抓取 | ➖ 低优先 |

### LenovoLegionToolkit (7.6k★)
| 功能 | 机制 | 对本机适用性 |
|---|---|---|
| **dGPU Deactivate** | NvAPIWrapper 枚举 dGPU 上进程 → 杀进程 / 短禁用设备逼 Optimus 断电; 悬停显示 P 状态+进程列表 | 💡💡**最大发现**: 直接命中我们"iGPU D3 功耗盲区"未调研项; MX150 空闲常驻 ~0.5-2W; 实现路径 = P/Invoke nvapi.dll (系统自带, 零依赖可行) 或 nvidia-smi 查询+设备禁用 |
| **Actions 自动化** (触发器×动作) | 插电/拔电/游戏启动/低电量/定时/合盖 等 20+ 触发器, 动作含运行脚本+环境变量注入 (LLT_IS_AC_ADAPTER_CONNECTED 等) | 💡 我们的 AC/DC 自动切换是其子集; 可扩展: 低电量触发器→切 EPP/计划 (已有告警, 差动作联动) |
| **CLI** (llt.exe feature get/set) | 命令行控制面 | 💡 可做: SysConsole.exe /set epp 40 类命令行 (脚本化友好) |
| Windows Power Mode ↔ 厂商模式映射 | 注册表 overlay | ✅ 我们已实现 (overlay 联动) |
| Custom Mode (功耗墙+风扇自定义) | Lenovo WMI (BIOS G9CN+ 才支持) | ❌ 本机固件无此接口 |
| Hybrid iGPU-only / Auto | EC 断 dGPU | 💡 同 dGPU Deactivate 思路 |
| RGB/BootLogo/ warranty 等 | Lenovo 专有 | ➖ 不适用 |
| CPU OC/UV 立场 | FAQ 指路 XTU/ThrottleStop | 与我们 11_文档结论一致 (TS 是正解) |

### Div-Acer-Manager (Acer, Linux)
- 新 Nitro/Predator 有 **WMI 风扇接口** (社区内核驱动调用) → 佐证"老 Aspire KB9022Q 无 WMI 风扇接口"是机型差异而非 Acer 全系缺失; 本机风扇线维持❌
- DAM-Max 有 Battery Limit/校准 → 同为acer-wmi-battery 接口族, 本机固件无 ❌
- Avalonia UI + daemon 架构 ➖ 参考价值低 (我们 WinForms 单进程已够)

## 四、结论

1. **我们的控制台在"老 Aspire Windows 开源控制台"生态位是独一份** — 没有可直接抄的 Acer 同类, 但 LLT/G-Helper 的**功能设计模式** (自动化规则/CLI/dGPU 管理) 全部可移植, 且都零依赖可实现
2. **最大新发现 = dGPU Deactivate 思路**: 命中我们自己的功耗盲区未调研项, MX150 空闲常驻功耗是续航上真实的未收割收益
3. 厂商专用接口 (功耗墙/风扇/充电限制) 再次确认本机固件无门 — 与 08/11 文档结论闭环
